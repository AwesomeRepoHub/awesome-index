## 怎么用

1. 先看合集导航，按你正在解决的问题选一个合集。
2. 合集里每张表按 Stars 排序，第一列是项目、第三列是热度、第四列是许可证。
3. 每个合集顶部有“30 秒选型”，写明什么情况下该选哪个，不用从头读。
4. 中文说明是筛选结果，不是项目自述的翻译；英文说明保留项目原文。


## 收录标准

只收录能跑起来、许可证明确、仍在维护的开源项目；同类只留一个首选。Stars 是热度参考，不是质量结论。


## 参与贡献

发现更好的项目或链接失效？在对应合集仓库开 issue 或 PR，流程见各仓库的 `CONTRIBUTING.md`。
