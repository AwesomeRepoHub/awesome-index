## 怎么用

1. 上面每张卡片是一个合集，点封面或标题进入。
2. 合集里每张表按 Stars 排序，写明用途、许可证，并用“30 秒选型”直接给结论。
3. 中文说明是我们的选型判断；`README.en.md` 里保留项目原文，方便对照。

## 收录标准

只收录能跑起来、许可证明确、仍在维护的开源项目；同类只留一个首选。长期停更但仍值得用的条目会在表格里标注。

## 参考的写法

目录结构、许可证标注与“反特性”提示的写法参考了 [sindresorhus/awesome](https://github.com/sindresorhus/awesome)、[awesome-selfhosted](https://github.com/awesome-selfhosted/awesome-selfhosted)、[awesome-mac](https://github.com/jaywcjlove/awesome-mac)；区别是这里的数字全部由 API 生成，不手写。
