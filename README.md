# GitHub 精选总导航

按主题导航 AwesomeRepoHub 的全部精选合集。

## 主题导航

- [AI 智能体精选](https://github.com/AwesomeRepoHub/awesome-ai-agents) — 收录智能体框架、工具调用、多智能体协作和任务自动化项目。
- [AI 编程精选](https://github.com/AwesomeRepoHub/awesome-ai-coding) — 收录 AI 编程助手、代码理解、代码审查和研发自动化项目。
- [自部署应用精选](https://github.com/AwesomeRepoHub/awesome-self-hosted) — 收录适合个人和小团队自行部署、掌握数据的开源应用。
- [效率工具精选](https://github.com/AwesomeRepoHub/awesome-productivity) — 收录笔记、知识管理、任务管理、搜索和个人工作流工具。
- [设计工具精选](https://github.com/AwesomeRepoHub/awesome-design-tools) — 收录 UI、图像、矢量、字体、设计系统和原型相关开源工具。
- [硬件与物联网精选](https://github.com/AwesomeRepoHub/awesome-iot) — 收录嵌入式开发、智能设备、传感器、固件和物联网平台。
- [电商开源精选](https://github.com/AwesomeRepoHub/awesome-ecommerce) — 收录商城、商品管理、订单、客户管理与电商运营工具。

## 收录原则

优先选择用途明确、文档完整、许可证清晰的开源项目。每条精选补充中文用途、适合人群、推荐理由和核验日期。

## 建设进度

目前处于合集框架初始化阶段，各主题仓库链接为规划目标，以 GitHub 实际创建状态为准。项目条目将在逐项筛选后补充。
